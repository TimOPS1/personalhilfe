# Personalhilfe

Prototyp einer Web-App zur kurzfristigen Personalkoordination zwischen Klassen einer Förderschule.

- Klassen melden Bedarf (Zeitraum: 1. Block, 2. Block, Mittagessen, 3. Block oder ganzer Tag)
- Andere Klassen schicken Erwachsene für einen oder mehrere Zeiträume
- Schulleitung mit Master-Ansicht (Demo-Passwort im Code, nur Prototyp)

**Stand:** reiner Frontend-Prototyp, alle Daten liegen nur im jeweiligen Browser. Für den echten Betrieb fehlen Backend (Realtime), echte Anmeldung und Web Push.
